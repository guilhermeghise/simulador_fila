# Simulador de fila

Este projeto simula filas G/G/c/5 por eventos discretos. Ele usa um gerador
congruente linear para criar os intervalos de chegada e atendimento, e exibe o
tempo e a probabilidade de cada estado da fila.

O programa executa dois cenarios: um e dois servidores.

## Como executar

```bash
python3 simulador_fila.py
```
